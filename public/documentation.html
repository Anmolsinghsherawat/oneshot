1. Executive Summary & Project Purpose

ONE SHOT ANIMATION is a high-craft content creation agency and ad scaling engine specializing in 3D/CGI animation, viral UGC video ads, and high-ROAS paid media campaigns.

This platform serves as a high-converting digital storefront designed to convert brand marketers and enterprise advertisers into qualified agency leads.

4. Security & Privacy Audit

  • Zero API Key Exposure: The codebase is 100% clean with zero embedded client API keys, secret tokens, or server credentials.
  • Secure Asset Delivery: All external video reels and images are streamed over HTTPS from trusted CloudFront and Unsplash CDNs.
  • Client-Side Forms: All lead forms operate safely in-memory without server risk.

5. Local Installation & Development

# 1. Unzip the project folder
cd oneshot-animation

# 2. Install dependencies
npm install

# 3. Launch dev server
npm run dev

# 4. Production Build
npm run build
